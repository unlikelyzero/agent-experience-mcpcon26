02Evals are the outcome

Each tier is scored two ways: by the evals teams already run, and by an agent doing real tasks. Same app, same pixels.

Method: what-iff Memory Manager, 4 tasks × 3 runs per tier per model, through Playwright MCP. Each tier is a semantics-only patch, with screenshots checked byte-identical. Every run is graded from app state, not the agent’s word.

03The takeaway

Accessibility is for people first. Agents benefit too.
The names, roles and state that people who are blind or have low vision rely on, through screen readers and other assistive technology, are the same interface an agent reads. Build it right for people, and agents can use it too.
