Tier 1 · Div soup

It says words. It never says what you can do.

What the agent got

- heading [level=1]: Memory Manager
- generic [cursor=pointer]: Memories
- generic [cursor=pointer]: Merge history
- generic [cursor=pointer]: User
- article [cursor=pointer]:
  - generic: Trip Planner
  - generic: Oct 21
  - generic: ⋮
  - paragraph: Prefers aisle seats on flights

What a screen reader says

  • “Memories. Merge history. Compaction log.”
  • “Trip Planner. Personality. October 21.”
  • “Vertical ellipsis.”
  • “Prefers aisle seats on flights.”

No tab, no checkbox, no button. None of the 14 memory cards has a control in the tree. The agent has to guess what is clickable.

Tier 2 · WCAG / Section 508

Every control has a name. Fourteen share it.

What the agent got

- tablist "Memory manager sections":
  - tab "Memories" [selected]
- list "Memories":
  - listitem:
    - checkbox "Select memory"
    - button "More actions"
    - paragraph: Prefers aisle seats on flights
  - listitem:
    - checkbox "Select memory"
    - button "More actions"

What a screen reader says

  • “Memories, selected, tab, 1 of 3.”
  • “Memories, list, 14 items.”
  • “Select memory, checkbox, unchecked.”
  • “More actions, button.” ×14

Passes the audit. But “More actions” for which memory? The agent finds out by position, and position is where it slips.

Tier 3 · Accessibility patterns

             Trip Planner, active":
    - checkbox "Select memory: Prefers aisle

    - button "More actions for: Prefers

What a screen reader says

  • “Prefers aisle seats on flights, Trip Planner, active.”
  • “Select memory: Prefers aisle seats on flights, checkbox.”
  • “More actions for: Prefers aisle seats on flights, button.”

Each control carries the row it acts on. Nothing to infer from layout.

How the evals work

Change only the semantics. Grade only the outcome.

1 · PIN

Real app

what-iff, Headlamp, Open MCT and webmcp-demo, each pinned to one commit.

2 · PATCH

Three tiers

A semantics-only patch per tier. A pixel diff proves every tier renders identically.

3 · AUDIT

axe

WCAG 2.2 AA violations per tier: the score an existing eval would report.

4 · SEED

Fresh state

Fixtures reset every run, each with a look-alike decoy (staging, a sibling memory).

5 · RUN

Agent

Claude Code headless through Playwright MCP, in an empty sandbox, no user settings, $1 cap.

6 · GRADE

App state

Read back from the API, kubectl or the database. A claim of "done" is checked, never trusted.

Every task on 4 apps, at 3 tiers, with 4 models (Opus 5.5, Sonnet 5.5, Haiku 4.5, Haiku 5.5), 3 runs each: 684 graded runs. Tokens and cost come from each run's stream; costs are list prices.
